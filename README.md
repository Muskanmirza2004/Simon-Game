# 🎮 Simon-Says-Game

A fun and interactive memory game built using HTML, CSS & JavaScript.
The game challenges players to remember and repeat an increasingly long sequence of colors.

# 🚀 Features
* Random color sequence generation
* Interactive button animations
* Game over effect & restart option
* Increasing difficulty with every level
* High score tracking

# 🕹️ How to Play
* Press any key to start the game.
* Watch the color sequence carefully.
* Repeat the same sequence by clicking the buttons.
* A new color is added after every correct level.
* Clicking the wrong button ends the game.

# 🛠️ Technologies Used
* HTML5
* CSS3
* JavaScript
